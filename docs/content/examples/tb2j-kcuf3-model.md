KCuF₃ is a quasi-one-dimensional, orbitally ordered type-A antiferromagnet.
The four-Cu polytype-a magnetic cell folds magnons relative to the one-Cu
pseudo-cubic perovskite frame used to index neutron spectra. This example
unfolds an **idealized Heisenberg model**, not a DFT-derived KCuF₃ spectrum
or a fit to its neutron data. The right-hand panel adds an *illustrative*,
not measured, flavor-dependent chain exchange to show fold mixing.

## Model and translation frames

Lake, Tennant, and Nagler's [INS analysis](https://arxiv.org/abs/cond-mat/0503128)
uses a pseudo-cubic frame with a = b = 4.126 Å, c = 3.914 Å (10 K),
nearest-chain AFM pair exchange Jc = 34 meV, and in-plane FM pair exchange
J⊥ = −1.6 meV. The model uses S = ½, collinear FM ab-planes stacked
antiferromagnetically along c, and omits Dzyaloshinskii–Moriya exchange,
quantum fluctuations, and the full orbital/lattice structure. Experimentally
the spins lie in the ab-plane; rotating this *isotropic* model's quantization
axis to z changes no energies. [Neutron diffraction](https://doi.org/10.1103/PhysRev.188.919)
reports type-A order with in-plane spins.

The script constructs the four Cu sites in the conventional I4/mcm-sized
cell. That cell already contains the two-layer AFM period — there is **no
second magnetic doubling**. For row-vector lattice conventions, the
pseudo-cubic parent maps to this cell through
`M = [[1,-1,0],[1,1,0],[0,0,2]]` with |det M| = 4. The parent frame retains
the measured uniform tetragonal strain; its translations are a comparison
frame, not symmetries of the orbital-ordered crystal. The magnetic reference
breaks body centering, so the four-Cu conventional-sized cell is used.

The unfolded path is Γ–X–M–Γ–Z–R–A in that pseudo-cubic frame. Neutrons'
(0, 0, 3/2) AFM zone center corresponds to Z = (0, 0, 1/2) here.

At Z the uniform model's Goldstone mode appears at 0.261 meV because TB2J
regularizes the BdG Cholesky decomposition. Its R = (1/2, 0, 1/2) in-plane
zone-boundary energy is 15.10 meV; the neutron analysis reports an 11 meV
scale. This mismatch is **not** evidence for an orbital-order effect: this
minimal linear-spin-wave model omits quantum renormalization (important for
S = ½ chains), anisotropy, and further exchanges. The spinon continuum
and longitudinal mode observed by INS are outside linear spin-wave theory.

## Reproduce

Install the `tb2j` extra and run from a scratch directory rather than the
source tree:

```console
pip install "unfolding[tb2j]" sympy
mkdir -p /tmp/kcuf3-model && cd /tmp/kcuf3-model
python /path/to/unfolding/examples/tb2j-kcuf3-model/run.py
python /path/to/unfolding/examples/tb2j-kcuf3-model/derive_chain.py
```

[`run.py`](https://github.com/mailhexu/unfolding/blob/main/examples/tb2j-kcuf3-model/run.py)
constructs `TB2J.magnon.Magnon` directly, checks the isolated-chain LSWT
limit and four-Cu/two-Cu folding equivalence, and writes
`kcuf3_unfolded.png` plus `kcuf3_results.json`.
[`derive_chain.py`](https://github.com/mailhexu/unfolding/blob/main/examples/tb2j-kcuf3-model/derive_chain.py)
verifies the analytic chain dispersion with SymPy and a numerical TB2J
oracle. The raw per-mode sum over all four primitive folds is one to
8 × 10⁻¹⁶ in both model variants; resolved group weights are binary
for the uniform model except two near-Goldstone path points where TB2J's
regularization crosses the integer-assignment threshold.

The committed site image is regenerated by `python docgen/fig_kcuf3_model.py`
(optional output PNG argument). That entry point runs the same checked model
and keeps its intermediate JSON outside the source tree.
